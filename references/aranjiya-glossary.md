# Anti-Aranjiya (محاربة العرنجية) UI Glossary

A comprehensive translation lookup table mapping awkward translationese/calques to natural Arabic software terminology.

| English / Feature | Clumsy Translationese (العرنجية) | Natural Arabic (الفصيح السليم) | Context / Notes |
|---|---|---|---|
| Successfully saved | تم الحفظ بنجاح / تم حفظ التغييرات بنجاح | **حُفظت التغييرات** | مبني للمجهول مباشر وموجز |
| The file has been deleted | تم حذف الملف بنجاح | **حُذف الملف** | لا داعي لكلمة "تم" |
| The money transfer has succeeded | عملية التحويل الخاصة بكم قد تمت بنجاح | **تم التحويل بنجاح** أو **أُرسل المبلغ** | حذف الحشو وضمائر الملكية الزائدة |
| Enter your email | قم بإدخال البريد الإلكتروني الخاص بك | **أدخل بريدك الإلكتروني** | فعل أمر + كاف الخطاب |
| Click here to view details | يرجى القيام بالنقر هنا لمشاهدة التفاصيل | **اضغط لعرض التفاصيل** | حذف "يرجى"، "القيام"، "هنا" |
| Updated automatically | يتم التحديث بشكل تلقائي | **يُحدّث تلقائيًا** | استخدام الحال بدل "بشكل + صفة" |
| Runs in background | يعمل بشكل مستمر في الخلفية | **يعمل باستمرار في الخلفية** | مفعول مطلق / حال |
| Sign in to your account | قم بتسجيل الدخول إلى الحساب الخاص بك | **تسجيل الدخول إلى حسابك** | المصدر للعنوان + كاف الخطاب |
| Reset your password | إعادة تعيين كلمة المرور الخاصة بك | **إعادة تعيين كلمة المرور** | "الخاصة بك" حشو لا يضيف معنى |
| Failed to connect to server | فشل في الاتصال بالخادم | **تعذّر الاتصال بالخادم** | "تعذّر" أو "لم نتمكن من" ألطف وأفصح |
| Edited by admin | تم التعديل من قبل المشرف | **عدّله المشرف** أو **بواسطة المشرف** | الفاعل المباشر بدل "من قبل" |
| Download your invoice | قم بتحميل الفاتورة الخاصة بك | **تنزيل فاتورتك** | "تنزيل" أفضل من "تحميل" للأخذ من السحابة |
| Upload file | قم برفع الملف الخاص بك | **رفع ملفك** | استخدام المصدر |
| You have received a new message | لقد تم استلام رسالة جديدة من أجلك | **وصلتك رسالة جديدة** | فعل ماضٍ رشيق ومباشر |
| Select an option | يرجى القيام باختيار أحد الخيارات | **اختر ما يناسبك** أو **اختر قيمة** | إزالة التردد والبطء |
| In case of emergency | في حالة حدوث حالة طوارئ | **عند الطوارئ** | إيجاز بليغ |
| At this current moment | في هذه اللحظة الحالية | **الآن** أو **حاليًا** | إزالة التكرار المترجم عن "at this moment" |
| Make sure that | تأكد من حقيقة أن | **تأكد أن** | لغة مباشرة |
| Due to the fact that | بسبب حقيقة أن الخدمة متوقفة | **لأن الخدمة متوقفة** | ربط لغوي مباشر |
| The aforementioned items | العناصر المذكورة أعلاه | **العناصر السابقة** | تعبيرات قانونية مترجمة لا تناسب الواجهات |
| Do not hesitate to contact us | لا تتردد في الاتصال بنا | **تواصل معنا** | إيجاز مهني واثق |
| As soon as possible | بأسرع وقت ممكن | **بأقرب وقت** أو **عاجلًا** | تعبير عربي فصيح |
| 2 hours ago | منذ 2 ساعات | **قبل ساعتين** | المثنى دون رقم، واستخدام "قبل" للأزمنة القريبة |
| 5 minutes remaining | 5 دقيقة متبقية | **5 دقائق متبقية** | جمع القلة المجرور بعد الأرقام 3-10 |
| 15 items | 15 عناصر | **15 عنصرًا** | تمييز مفرد منصوب للأرقام 11-99 |
| 100 users | 100 مستخدمين | **100 مستخدم** | مفرد مجرور للأرقام 100+ |
| Transfer succeeded | عملية التحويل الخاصة بكم قد تمت بنجاح | **تم التحويل بنجاح** أو **أُرسل المبلغ** | حذف العرنجية المركبة وضمائر الملكية الفضفاضة |
| Deploy in progress | جاري عمل deploy للتطبيق | **جاري النشر** أو **يُطلق التطبيق الآن** | استبدال التراكيب الهجينة بمصطلحات واضحة |
| Build failed | يرجى العلم بأن الـ build قد فشل | **تعذّر البناء** | إيجاز حاسم وحذف "يرجى العلم بأن" |
| Connection details | تفاصيل الاتصال الخاصة بقاعدة البيانات | **بيانات الاتصال بقاعدة البيانات** | حذف "الخاصة بـ" واستخدام "بيانات الاتصال" |
| Environment variables | متغيرات البيئة الخاصة بك | **متغيرات البيئة** | لا حاجة لنسب المتغيرات للمستخدم بـ "الخاصة بك" |
| View logs | اضغط هنا من أجل مشاهدة الـ logs | **عرض السجلات** | استخدام المصدر وحذف الروابط الركيكة |
| Storage quota | مساحة التخزين الخاصة بك | **المساحة التخزينية** أو **الحصة التخزينية** | مصطلح مهني فصيح وموجز |
| Scheduled tasks | مهام مجدولة تم إنشاؤها من قبلك | **مهامك المجدولة** | حذف نائب الفاعل "تم إنشاؤها من قبلك" |
